# Checkpoints

Major milestones for the project, derived from [execution-plan-10.md](execution-plan-10.md) (dated 2026-09-01). Each checkpoint has a goal, an exit criterion that can be checked (a command, a file, a number), and a status. Detail of the work itself goes in [UPDATES.md](UPDATES.md); what to do when a checkpoint's work fails goes in [ERRORS_AND_FALLBACKS.md](ERRORS_AND_FALLBACKS.md).

Status values: `not started` · `in progress` · `done` · `blocked` · `dropped` (with the reason) · `needs decision`.

```

- Goal: <one sentence>
- Plan phase: <phase number>
- Exit criterion: <what must be true, checkable by command or file>
- Depends on: <CP ids>
- Status: <status> (<date>)
- Evidence: <results file / UPDATES entry id>
- Fallback: <ERRORS_AND_FALLBACKS feature id>
```

## CP-5 — Multi-seed PnL suppression and generalisation gap

- Goal: the plan's Phase 9: uncertainty on PnL suppression and on the in-distribution vs held-out detection gap.
- Plan phase: 9
- Exit criterion: PnL suppression for all three Watchdog seeds (`main`, `main_s2`, `main_s3`), with mean ± 95% CI, and a CI on the recall gap between in-distribution and LATEBURST.

## CP-7 — Improve detection of unseen (sparse) spoofing

- Goal: close the gap between the plan's target result (Watchdog ahead on unseen attacks) and the current one (recall 0.24 vs the rule's 0.89).
- Plan phase: 3, 4 (extension; not in the original plan)
- Exit criterion: a change chosen on test-split evidence only, retrained over 3 seeds, then scored once on a **new** pre-registered attacker committed before any of its data exists. The result is reported whichever way it goes.
- Depends on: CP-1, CP-3
- Status: done (2026-10-21). Round 1 (causal label + γ 0) partly passed DRIP-ATK (recall 0.26). Round 2 (training coverage) passed pre-registered REVERSAL-ATK: recall 0.981, legitimate FPR 0.006, F1 0.986 vs rule 0.591 (U-019 to U-025). Follow-ups done (U-026): synthetic market, layering, PnL suppression and all replay data re-scored post-hoc. The consolidated table is to be refreshed in CP-8.
