RL Finance Watchdog

Adversarial reinforcement learning for detecting limit-order-book spoofing · built on LOBSTER data, 2012-06-21

Can a reinforcement learning agent learn to detect previously unseen order-book manipulation — spoofing — while keeping a low false-positive rate on legitimate activity, without being told what spoofing looks like?
This page reports simulation results, including those that went against the hypothesis. No labelled real-world spoofing data exists, so no claim of real-world detection capability is made. Legal reference: CEA §4c(a)(5)(C) (Dodd-Frank §747).
Audit finding — read before any detector number. The manipulation label is readable from two of the detector’s own input features, so a zero-parameter signature scores order-level F1 0.997 in-distribution and 0.995 on a held-out attacker at a false-positive rate of 0.000, and gradient boosting fitted on the train split beats the RL Watchdog on every bucket. The detection task as posed is close to a tautology, so the detector figures below are a documented negative result rather than a working surveillance method. The environment also grants surveillance perfect attribution of orders and trades to one participant — establishing that is the hard part of real spoofing surveillance, and it is assumed away. Full write-up in docs/FINAL_AUDIT.md §2.

Honest limitations

  • The detection task is close to a tautology: the label is readable from two observation features, a zero-parameter signature scores 0.997, and gradient boosting beats the RL detector everywhere. Reinforcement learning is not justified for the detector.
  • Perfect attribution is assumed: surveillance is told which orders and trades belong to the monitored participant. Establishing that is the hard part of real spoofing surveillance.
  • Profitable manipulation is demonstrated only under the replay impact model; it does not survive the synthetic market.
  • The Watchdog misses sparse spoofing, confirmed by two pre-registered tests — but see above for why that is a statement about the learner rather than about detectability.
  • LOBSTER carries no participant identities, so the Watchdog cannot be run on real order flow; only the rule can.
  • One trading day, five stocks. Spoofing is unprofitable on the wide-spread stocks under calibrated impact.
  • The manipulation label is a proxy for intent (trading the opposite side while an order rests), not a legal determination.
